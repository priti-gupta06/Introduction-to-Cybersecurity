#10 common cyber threats

##1. phishing
fake message used to steal information.
example - fake bank for asking login details

##2. malware 
harmful software that damages or steal data.
example - computer virus

##3. ransomware 
encrypts files and demands for money.
example - wannacry attack

##4. DDoS 
overloads a server with huge traffic.
example - websites become unavailable

##5. password attack
attempts to steal or guess password
example - brute force attack

##6. MITM
the attacker intercepts communication.
example - intercepting data on public wi-fi

##7. SQL injection
a malicious SQL commands attack a database. 
example - bypassing a website login

##8. spoofing 
pretenting to be a trusted source.
example - fake bank website 

##9. insider threat
authorized person misuses access.
example - employee stealing company data.

##10. social engineering
manipulating people to reveal information. 
example - fake IT support asking for a password

## conclusion 

cyber threats can affect indiviuals and 
organization.

security awareness, strong password, 
multifactor authentication, software updates, user education, and appropiate
security controls 
can help reduce cybersecurity risks
